# Bilder til nettsiden

Siden plukker opp bildene automatisk når de ligger med riktig filnavn. Mangler et bilde, vises initialer eller mørk bakgrunn i stedet.

**Toppbilde:** `hero.jpg` – liggende actionbilde, gjerne 2400 px bredt.
